One gate for three packages. R7: what you see after a change to many trips (Decision 0073). R9: how Fill and Copy show which time periods were paired (Decision 0074). R11: the compare-patterns view (Decision 0075). Fictional data from the Southbound route.

  • Marked rows keep the accent bar and shading of the moved-row marker used on the Route and Blocking tabs. With six or more changed trips there is no flash.
  • "12 above, 9 below" counts marked rows outside the visible part of the table. Next ↓ and ↑ Previous scroll to the next marked row and move keyboard focus to it.
  • Select changed trips turns the marks into a selection, so the usual selection bar takes over (for example, to shift them all again). Clear marks removes the line and the shading.
  • With one to five changed trips there is no status line. The rows flash once, and the first one is scrolled into view.

Use :08 for…

  • Columns are every segment the direction's patterns run, in timetable order. "·" means that pattern does not run the segment.
  • A highlighted cell differs from another pattern's value for the same segment at an overlapping time. Clicking it opens "Use this value for…". The write goes through the same preview, save and Undo last segment copy as Copy segments.
  • Align by time switches to one row per clock interval, cut at every pattern's period boundaries. Each cell then lists each pattern's value ("WR–EV :08 · WS–EN :07").
  • Opens from Runtimes actions → Compare patterns…, for the selected route, direction and day.
