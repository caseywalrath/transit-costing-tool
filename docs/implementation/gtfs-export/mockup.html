GTFS export: dialog mock-up

Package E3 of the phase E plan (docs/implementation/gtfs-export-phase-e.md), rules in Decision 0090. One page with five sections, not steps. Numbered markers tie the frame to the notes below it. Frame 1 shows an RTD import (routes 31, 0, 0L); its counts are illustrative; frame 2 is the Federal BRT example, whose timepoints have no locations.

  1. 1
    Routes

    "All N Routes" or a checklist (the same chooser as the import's Routes step, with search). Only Routes with Trips in the profile are counted.

  2. 2
    Blocks

    Defaults to the Scenario's last-used Blocking scenario; "None" writes no block_id.

  3. 3
    Dates

    Remembered on the Scenario (G-E2). New Scenarios start blank; Export stays disabled until both dates are set.

  4. 4
    Holidays

    Each date runs one service day, default Holiday; custom days such as "Holiday 2" appear in the list (G-E5). Dates outside the range or repeated cannot be added.

  5. 5
    Map lines

    Straight lines (G-E3 A) or none.

  6. 6
    Checks

    Run as you edit. A refusal disables Export and shows frame 2's list.

  7. 7
    After export

    A notice: "Exported 1,330 trips on 3 Routes. Report downloaded." No change to the Scenario except the remembered values.
